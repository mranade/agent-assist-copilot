# Slow speeds troubleshooting

Use this when the customer is connected but speeds are slower than their plan.

## Steps for the agent
1. Check the customer's plan tier (KB-110). Many "slow" reports are customers on the 300 Mbps plan expecting gigabit speeds.
2. Ask the customer to run a speed test on a device plugged into the gateway with an Ethernet cable. Wi-Fi speed tests are not a reliable measure of the line.
3. Recommend the 5 GHz network or a mesh extender for Wi-Fi coverage if the wired result is within 80% of the plan speed. The line is healthy.
4. If the wired result is below 80% of the plan speed, run a line check and power-cycle the gateway (KB-105). If still slow, schedule a technician (KB-115).
