# Late fee waiver policy

The late fee is $10 and is charged when a payment is more than 10 days past due.

Agents may waive one late fee per customer in any 12-month period, without supervisor approval. Check the account's waiver history first. If a waiver was already used in the last 12 months, a second waiver requires supervisor approval (KB-120).

After a waiver, offer to set up autopay (KB-116) so it doesn't happen again.

## Steps for the agent
1. Ask for the last four digits of the account number and the account PIN to verify the caller (KB-117).
2. Check the account's waiver history for a waiver in the last 12 months.
3. If no waiver was used in the last 12 months, waive the late fee. A second waiver in 12 months requires supervisor approval (KB-120).
4. Offer to set up autopay (KB-116) so it doesn't happen again.
